# Contributing to The Hishab Project

Thank you for considering to contribute to The Hishab Project! We welcome all forms of contributions, including code, documentation, bug reports, feature requests, and more.

This project is licensed under the **GNU General Public License (GPL)**. By contributing, you agree to license your work under the same license.

## How to Contribute

### 1. Reporting Bugs

  - Check if the issue already exists in the [Issues](https://github.com/nikashlabs/hishab/issues) tab.
  - Provide a clear title, description, and steps to reproduce.
  - Include logs or screenshots if applicable.

### 2. Requesting Features

  - Explain the use case and why it’s valuable.
  - Suggest implementation ideas if possible.

### 3. Contributing Code

#### Prerequisites

- Familiarity with Git/GitHub.
- Basic knowledge of [go](https://go.dev/).
- Basic knowledge of web application development.
- Ensure your contributions align with the GPL license.

#### Steps:

1. **Fork** the repository.
2. **Create a branch** for your work:

   ```sh
   git checkout -b feat/your-feature-name
   ```

3. Commit changes with clear, descriptive messages.
> Check the already existing branch names, commits, PR names etc and try to be consistent with the existing codebase. 
4. Push to your fork and open a Pull Request (PR).
5. Discuss and iterate based on feedback.


### 4. Code Guidelines

- Follow the project’s coding style (e.g., indentation, naming conventions).
- Add tests for new features or bug fixes.
- Document your changes in the code or README.md if needed.

### 5. Review Process

- Maintainers will review PRs and may suggest changes.
- Ensure all CI checks (tests, linting) pass.
- Be responsive to feedback.

### 6. Other Contributions

- Documentation: Fix typos, improve clarity, or add examples.
- Community Help: Answer questions in discussions or issue threads.
